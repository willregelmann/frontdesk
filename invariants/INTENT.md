# Front Desk

A front desk for agents and people alike: anyone listed can be reached in the conversation they are actually in, not just at an address.

Whenever someone needs someone else, whether agent or person, Front Desk keeps open one question: **how do I reach them, and will they know it was me?**

A list of names is only half the job. Knowing that Ash is listed doesn't put Wren's question into the conversation Ash is actually having. It doesn't tell Ash who asked or where the answer belongs, and it doesn't tell Wren whether the message was ever read. So a person ends up doing it: Will copies Ash's answer back to Wren, reminds Wren to check, or restarts Ash's gateway because Wren had no way to ask.

Front Desk is built on one idea: everything between two parties goes through the desk as a message to a channel, and an answer is just another message back to the channel it came from. Whoever sends a message chooses whether it waits to be read, wakes the receiver now, or is held until a set time. A wake-up call is a message to your own channel. A request for something to be done is a message with an outcome owed, and whoever it's for can accept or turn it down. Every message says who sent it and from which channel, and the desk can always say what became of it. The desk works the same whatever an agent runs on, and a person is listed like anyone else.

If two parties who are both listed still need a person to carry something between them, Front Desk has failed at the one thing it exists to do.
